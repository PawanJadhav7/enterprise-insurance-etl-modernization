# Enterprise Insurance ETL Modernization Platform

This project demonstrates an enterprise-grade insurance data integration and data warehousing solution for a Manulife / John Hancock–style financial services environment.

## Project Focus

- Informatica IICS / PowerCenter ETL design
- Azure cloud data platform
- Databricks Lakehouse architecture
- Salesforce integration
- SQL-based data warehousing
- SCD Type 1, Type 2, and Type 3
- Advanced SQL transformations
- Data quality and reconciliation
- PII/PHI governance
- CI/CD using GitHub Actions

## Target Tech Stack

- Informatica IICS / PowerCenter
- SQL
- Python
- PySpark
- Azure Data Lake Storage Gen2
- Azure Data Factory
- Azure Databricks
- Delta Lake
- Unity Catalog
- Azure SQL Database
- Salesforce CRM
- Azure Key Vault
- Microsoft Purview
- Power BI
- GitHub Actions
