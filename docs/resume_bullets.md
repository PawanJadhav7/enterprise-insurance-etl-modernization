## Project Title

Enterprise Insurance ETL Modernization Platform

## Resume Summary Version

Designed an enterprise-grade insurance ETL modernization and data warehousing platform for a Manulife / John Hancock–style financial services environment using Informatica IICS / PowerCenter, SQL, Azure, Databricks, Salesforce integration, SCD Type 1/2/3, data quality controls, PII/PHI governance, and Power BI reporting.

## Senior ETL Developer Bullets

- Designed an enterprise insurance ETL modernization platform integrating Salesforce CRM, policy administration, claims, billing, annuity, and long-term care source systems into a governed data warehouse architecture.

- Created Informatica IICS / PowerCenter mapping designs using Source Qualifier, Expression, Lookup, Router, Aggregator, Update Strategy, and parameterized workflow patterns for scalable enterprise ETL processing.

- Designed SCD Type 1, Type 2, and Type 3 data warehousing patterns for customer, policy, product, advisor, claim status, and risk-tier dimensions.

- Developed advanced SQL design patterns for dimensional modeling, source-to-target reconciliation, incremental loading, data quality validation, duplicate detection, and claim/premium analytics.

- Built a regulated insurance data model supporting claims analytics, policy lifecycle reporting, premium collection, advisor performance, annuity transactions, and long-term care benefit utilization.

- Designed source-to-target reconciliation controls using batch control tables, reject tables, data quality result tables, batch IDs, source counts, target insert/update counts, and reject counts.

- Created PII/PHI governance documentation covering tokenization, hashing, masking, restricted raw data access, role-based access control, audit logging, and secure curated analytics tables.

- Designed an Azure-based lakehouse architecture using Azure Data Lake Storage Gen2, Azure Data Factory, Azure Databricks, Delta Lake, Azure SQL, Azure Key Vault, Microsoft Purview, and Power BI.

- Documented CI/CD strategy using GitHub Actions for portfolio implementation and Azure DevOps as an enterprise alternative for Dev, QA, UAT, and Production deployment workflows.

- Created Power BI dashboard specifications for executive insurance KPIs, claims analytics, policy analytics, billing performance, advisor performance, annuity analytics, long-term care reporting, and data quality monitoring.

## Azure / Databricks Bullets

- Designed a Medallion Architecture using Bronze, Silver, and Gold layers to support raw ingestion, data cleansing, privacy-safe transformations, and curated insurance reporting.

- Modeled Databricks and Delta Lake processing patterns for high-volume claims, policy, billing, customer, advisor, annuity, and long-term care datasets.

- Designed cloud landing and staging patterns using ADLS Gen2 and Azure SQL for batch, API, file, and CDC-based ingestion from enterprise insurance source systems.

- Defined lakehouse governance patterns using Unity Catalog, Microsoft Purview, Azure Key Vault, RBAC, audit logs, masked views, and sensitive data classification.

## Data Quality / Governance Bullets

- Designed an enterprise data quality framework covering completeness, validity, uniqueness, referential integrity, reconciliation, timeliness, duplicate detection, and reject handling.

- Built audit-ready ETL control structures including etl_batch_control, etl_step_control, etl_reject_records, and etl_data_quality_results.

- Established idempotent pipeline design patterns using business keys, record hashes, batch IDs, watermarks, MERGE logic, and one-current-record validation for SCD Type 2 dimensions.

- Defined PII/PHI-safe analytics patterns to ensure raw sensitive fields are restricted in Bronze, protected in Silver, and exposed through masked or tokenized Gold reporting tables.
